title: "07 · Agent Library og biblioteker"
sidebar_position: 7
---

Agent Library er katalogen over tilgjengelige agenter. Skill mellom personlige, team-/prosjektbaserte og felles agenter. Hver oppføring bør beskrive eier, formål, versjon, modellkrav, kilder, tools, skills, tilgang og evaluering.

Når en agent deles, skal ikke eierens personlige kilde- eller verktøytilganger følge med. Brukerens effektive rettigheter kontrolleres ved kjøring. Kopiering og tilpasning bør være mulig der eierskap og policy tillater det.

| Bibliotek | Ressurs |
|---|---|
| Agent Library | Ferdig agentdefinisjon |
| Skills Library | Arbeidsmetoder |
| Knowledge Library | Kunnskapskilder og samlinger |
| Tool Library | Godkjente verktøy og integrasjoner |

De fire bibliotekene er en foreslått logisk inndeling, ikke nødvendigvis fire uavhengige tjenester.
