Skills er gjenbrukbare arbeidsmåter: instruksjoner, prosedyrer, maler, referanser, valideringskriterier og eventuelt anbefalte verktøy. Et tool utfører en funksjon; en skill forklarer hvordan en oppgave skal løses.

| Tool | Skill |
|---|---|
| Hent dokument | Analyser dokument |
| Opprett issue | Planlegg utviklingsoppgave |
| Søk i kilder | Gjennomfør kildebasert research |

Skills Library bør støtte personlige, team- og institusjonelle skills med eierskap, versjon, tilgang og eventuell godkjenning. En agent kan bruke mange skills; samme skill kan brukes av flere agenter. Ferdigheter skal ikke kunne heve privilegier, overstyre policy eller aktivere ikke-godkjent kode. Vurder både instruksjonsinnhold og eventuelle kjørbare ressurser før publisering.
