## Geografisk og juridisk tilgjengelighet av KI-modeller

Nye modeller kan bli tilgjengelige globalt eller i USA før de tilbys med avgrenset europeisk behandling. Microsoft Foundry er et eksempel på en tjeneste der modellutvalg og behandlingsgeografi varierer med utrullingstype. En europeisk ressursadresse garanterer ikke europeisk behandling. Tredjelandsoverføring må vurderes og ha nødvendig grunnlag der personopplysninger overføres; EØS-behandling er heller ikke alene tilstrekkelig for GDPR-etterlevelse.

HVLs strategi er et felles modellregister med godkjente modeller i flere behandlingsmiljøer. Brukere kan velge, eller plattformen kan velge automatisk ut fra kvalitet, språk, kostnad, kapasitet og sikkerhet.

## Eksempler på modeller HVL kan tilby

Eksempler fra prosjektets modellvurderinger, ikke en liste over godkjente eller bekreftet tilgjengelige modeller:

| Driftsform | Eksempel på modellfamilie | Aktuell bruk |
|---|---|---|
| Microsoft Foundry | OpenAI GPT, inkludert mindre modellvarianter | Generell KI-assistanse, analyse, programmering og agentoppgaver. |
| Microsoft Foundry | Anthropic Claude (Haiku, Sonnet og Opus) | Dokumentarbeid, analyse, programmering og sammensatte oppgaver. |
| Microsoft Foundry | Mistral, eksempelvis Mistral Large | Flerspråklig tekstbehandling, analyse og agenter. |
| Lokal drift ved HVL | OpenAI gpt-oss, eksempelvis 20B og 120B | Resonnering og agentoppgaver uten å sende selve modellforespørselen til en ekstern modellleverandør. |
| Lokal drift ved HVL | Utvalgte modeller fra Mistral, eksempelvis Mistral Small | Flerspråklige oppgaver, dokumentarbeid og lokale assistenter. |
| Lokal drift ved HVL | Nasjonalbibliotekets NB-Whisper | Norsk tale-til-tekst og transkripsjon. |
| Lokal drift ved HVL | Chatterbox | Tekst-til-tale og lydproduksjon. |
| Andre godkjente leverandører og nasjonale tjenester | Modeller som tilbys gjennom egnede avtaler og behandlingsmiljøer | Utvidelse av modellutvalget og kapasiteten etter behov. |
| Lokal drift / nasjonalt tilbud | Nasjonalbibliotekets Borealis | Kandidat for norsk responsgenerering på bokmål og nynorsk. |

Tilgang til modeller via API er ikke det samme som tilgang til alle funksjoner i leverandørens ferdige produkt. For Foundry må modell, utrulling og avtalevilkår godkjennes særskilt. For lokal drift må kvalitet, lisens, modellstørrelse og samtidighet vurderes.

## Lokal regnekraft og digital suverenitet

Fire Dell GB10-maskiner er anskaffet til utvikling, testing og gradvis produksjon. De kan suppleres av godkjente kommersielle og nasjonale tjenester. Kapasitet og samtidighet må måles før utrulling.

Økt lokal kontroll kan kreve mer maskinvare der sikkerhetskrav, forskningsbehov eller manglende nasjonale tilbud tilsier det. En mulig investering på rundt 2 millioner kroner på sikt er et foreløpig planleggingstall, ikke et dimensjonert kostnadsestimat, tilbud eller vedtatt anskaffelse. Dataklasser, samtidighet, kvalitet, nasjonale alternativer, energi, drift og kompetanse må inngå i et investeringsgrunnlag.
